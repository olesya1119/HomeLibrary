# HomeLibrary

Веб-приложение для ведения домашней библиотеки.

# Создание базы данных

Все SQL скрипты находятся в Store.DatabaseScripts

# Запуск

Для работы требуется разместить .env в корне MVC
```env
DB_CONNECTION_STRING=Server=.;Database=HomeLibrary;Trusted_Connection=True;TrustServerCertificate=True;
```
